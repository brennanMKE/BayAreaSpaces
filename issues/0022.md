# 0022 — JSON adapter for standalone documents

| | |
|---|---|
| **Status** | open |
| **Module** | adapters |
| **Platform** | macOS |
| **First seen** | 2026-08-05 |

## Description

Fetch a standalone JSON document and map a bespoke shape onto the canonical schema. Two consumers with quite different shapes.

## Expected behavior

**Maker Nexus — undocumented public cache.** `storage.googleapis.com/makernexus_amilia_activities_cache/events.json`. Dict keyed `YYYY-MM-DD_<amiliaId>`; **use the key as the UID**. Fields: `Name`, `Description`, `Url`, `CategoryName`, `Price`, `SpotsRemaining`, `StartDate`/`EndDate` as ISO-8601 with `-07:00`. 30 forward-looking events, `Last-Modified` same day. Richer than their ICS for the same events, so it wins the dedupe merge on price and capacity.

**The Crucible — WooCommerce Store API.** `wp-json/wc/store/v1/products` with `per_page=100` and **`orderby=date`**.

- **`orderby=date` is load-bearing.** Without it the endpoint returns HTTP 200 and valid JSON with `X-WP-Total: 98` instead of 353 — 72% of the catalog silently missing, covering only 40 of 216 live courses. Nothing about the response looks wrong. Assert the total.
- Paginate on `X-WP-TotalPages`. `page=99` returns 200 with `[]`, not an error, so **never paginate until-error**.
- Dates live in `attributes[].terms[].name` as `MM/DD/YY H:MM am/pm` local.
- **Drop the literal sentinel `01/01/70 12:00 am`** — naive `%y` parsing maps it to 2070 and it sails past every horizon check.
- Do not filter on its categories: 60+ one-off per-product categories equal the class title. Use the blob's `department` (issue 0021).

## Notes

The `orderby=date` trap is the most dangerous shape found in the whole survey — correct-looking and quietly amputated. It was caught only because two independent sources disagreed on the count.

Maker Nexus's GCS bucket cannot be enumerated anonymously (401 on `storage.objects.list`). `activities.json` and `camps.json` were found by name-guessing and are stale and dateless; there may be a classes cache worth asking staff about.
