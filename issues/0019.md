## Description

WordPress "The Events Calendar" REST API. Richer than the same site's ICS export — venue, cost, categories, organizer, ticket status — so it outranks it. Build once, reuse wherever TEC appears.

## Expected behavior

- `GET /wp-json/tribe/events/v1/events?start_date=YYYY-MM-DD&per_page=50`, paginate on `next_rest_url`.
- Unescape HTML entities in `cost` — Ace returns `&#036;20.00`.
- Keep `cost` as source text. **Do not parse to float**; "sliding scale $10–30" and "free for members" are real values.
- Map `utc_start_date`, venue, organizer, categories, `is_virtual`, ticket status onto the canonical schema.

## Notes

Currently one consumer: Ace Makerspace, 92 upcoming events over 2 pages. Verified working — the registry entry was flipped from `verified: false` to `true` once fetched, having previously been inferred from a `tec-api-version` meta tag.

**Detection heuristic for future spaces:** `?ical=1` subscribe links or `tec-api-version` in page meta means both an ICS feed and this REST API exist.

**Counter-example worth knowing:** The Crucible's pages carry `tribe-*` CSS class names but TEC is *not installed* — every `wp-json/tribe/*` route 404s. The classes are inert Avada compatibility CSS. Do not let class names talk anyone into a `tribe_rest` source.
