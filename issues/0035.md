## Description

19 additional Bay Area spaces were found by mining `makernexuswiki.com`, plus the original brief's unverified leads. None have been checked.

## Expected behavior

Research each on the same protocol as the existing 11 — fetch every candidate, record status/content-type/count, document dead ends — and write `spaces/<id>.md` for the viable ones.

**Most promising:**

- **The Compound Gallery** (Emeryville) — screen printing, letterpress, ceramics, metal, wood, plus an Art Lab. Likely a real class catalog.
- **Department of Spontaneous Combustion** (Oakland) — fire arts, public Tuesdays, a standing weekly event worth capturing.
- **Queerious Labs**, **Girls Garage** (Berkeley), **Robot Garden** (Livermore), **Lower 48** ✓ done.
- **Santa Clara Adult Ed woodshop** — runs on ASAP Connected, which may expose a course feed.

**From the original brief, still unverified:** Double Union, The Shed, MakeX, Port Product Lab, SFPL makerspaces; Counter Culture Labs (see 0033), Mothership HackerMoms, Circuit Launch, Bay Area Maker Farm, PEV Works; BioCurious, School of Visual Philosophy, Foothill College Makerspace, Kitchentown, Coyote Grange; Chimera Arts, Cyber Garage, Benicia Makerspace.
