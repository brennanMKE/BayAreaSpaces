# 0037 — Raw-archive test fails for ~7 hours a day because the fetcher dates from wall-clock UTC

| | |
|---|---|
| **Status** | open |
| **Module** | fetch |
| **Platform** | macOS |
| **First seen** | 2026-08-05 |

## Description

`tests/test_cli.py::test_raw_archive_is_written_before_anything_parses` asserts the raw payload lands in `raw/{FIXED_NOW.date()}` — `2026-08-05` — but `Fetcher` stamps the directory from wall-clock UTC rather than from the run's injected clock. It passes while UTC and the fixture date agree and fails once UTC rolls over, so it is red for roughly seven hours a day.

Found by the issue 0018 agent, which verified it is pre-existing by stashing its own work and re-running on the clean tree: **554 passed, same 1 failed**. It correctly left the fix alone rather than mixing it into 0018's commits.

## Steps to reproduce

1. Set the machine clock so UTC is past midnight relative to `FIXED_NOW` (or simply run between roughly 17:00 and 24:00 Pacific).
2. `uv run pytest tests/test_cli.py::test_raw_archive_is_written_before_anything_parses`

## Expected behavior

The raw archive path derives from the run's clock, which tests inject, so the test is deterministic at any hour.

## Actual behavior

`Fetcher` uses wall-clock UTC directly; the assertion misses by one day for part of each day.

## Notes

Two things to decide, and they are separable:

1. **The test** is straightforwardly wrong to assume the two clocks agree.
2. **The pipeline behavior** deserves a look too. `raw/` is dated by UTC while the run is a Pacific-evening job — at the scheduled 03:15 Pacific the UTC date matches, so production is not currently affected. But the repair workflow diffs `raw/YYYY-MM-DD/` directories by date, and a run that straddles UTC midnight would split one night's payloads across two directories. Threading the run clock through the fetcher fixes both.

Related: issue 0006 (fetch layer) owns the archive path; issue 0017's `health.json` publishes `raw_path` and the repair candidates' `raw_paths[]`, so a split would show up there.
