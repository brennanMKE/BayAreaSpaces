## Description

Last-resort extraction for pages with no stable selectors. Used only after every deterministic route has failed.

## Expected behavior

1. Fetch, strip `script` / `style` / `nav` / `footer`, convert to text with `trafilatura` or `readability-lxml`.
2. Truncate to roughly 6k tokens; chunk by date heading if longer.
3. Send to LM Studio with a strict JSON schema and today's date as an explicit anchor (issue 0027).
4. Validate against Pydantic. Retry once with the error appended; quarantine on second failure.

## Notes

**Registered consumers, and both are edge cases:**

- `noisebridge` `wiki-recurring` — the MediaWiki wikitext. Intended to be run **once** and converted to hand-maintained RRULEs (issue 0026), then disabled.
- `maker-nexus` `classes-week-view-embed` — already `enabled: false`. The markup is regular enough to parse deterministically (`p.dayofweek` = `YYYY-MM-DD (Dayname)`, `p.sessiontitle` = `Title <br> at HH:MM AM/PM`), and it is strictly worse coverage than the gCal. Kept only as a staleness cross-check.

So this adapter may end up with **zero** active consumers, which is the desired outcome. Build it, but do not go looking for work for it.

A browser (Playwright/WebKit behind a CLI) is **not** needed yet — no registered source requires JS rendering. Do not build one to solve a problem that has not appeared. If it becomes necessary, the seam is a CLI taking a URL and returning rendered HTML or extracted JSON, so the implementation can be swapped later.
