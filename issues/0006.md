## Description

The HTTP layer every adapter sits on. These are volunteer nonprofits on shared hosting, and this layer is where the project's good-citizen commitments are actually enforced rather than merely documented.

## Expected behavior

- One `httpx` client, HTTP/2, follows redirects, 30s timeout, 2 retries with backoff.
- **2 seconds between requests to the same host**, honoring per-space `rate_limit_seconds` (Ace's `robots.txt` sets `Crawl-delay: 10`).
- `robots.txt` honored per host via `urllib.robotparser`, cached per run. Path-level disallows bind regardless of which group we match.
- Honest User-Agent from the registry. **Never** impersonate a browser or another crawler — see the robots.txt section in `CLAUDE.md`.
- Conditional GET: `ETag` / `Last-Modified` stored per source; a 304 skips parsing and just bumps `last_seen`.
- Every response body written verbatim to `raw/YYYY-MM-DD/{space_id}-{label}.{ext}` before parsing. Never mutate `raw/`.
- On failure after retries: mark the source `failed` and **carry forward the previous run's events**. A transient 503 must never silently delete a space.

## Actual behavior

No fetch layer.

## Notes

**Return status, content type, body and byte count separately.** Do not collapse them into a success boolean. The survey found, live: 200 with `text/html` for `?format=ical`; 200 with a byte-identical homepage for `?ical=1`; 200 with an unfiltered full list from a supposed category feed; 404 with a valid populated RSS body; and 404 carrying `Content-Type: application/rss+xml` over a 1.35 MB HTML body. Adapters need all four facts to decide, and the layer must not pre-judge.

Two sources are large — Sudo Room's export is 8 MB and Maker Nexus's ICS is 11 MB. Conditional GET matters here, and `raw/` retention is capped at 30 days for a reason.
