## Description

The highest-value adapter: `ics` alone covers Ace, Sudo Room, Noisebridge, Frontier (×2), Humanmade (×2), The Box Shop and Hacker Dojo. This is the reason the project is written in Python.

## Expected behavior

- Parse with `icalendar`, expand recurrences with `recurring-ical-events` over today → today+`horizon_days`.
- Handle `DTSTART;VALUE=DATE` (all-day), floating times with no `TZID`, and both bare-UTC `Z` and `TZID=` forms **within the same feed** — Sequoia Fabrica's calendar mixes them.
- Normalize Luma's multi-day-as-all-day behavior, which otherwise looks wrong when merged.
- Return post-expansion, horizon-clipped events. Raw VEVENT counts are close to meaningless here: Sequoia Fabrica has 89 VEVENTs and ~7 live; Maker Nexus 3645 and 171; Sudo Room 5057 pre-expanded to 2058 and 73 in horizon.
- Preserve the source UID for namespacing as `{space_id}:{source_uid}`.

## Notes

**Unbounded RRULEs are a real hazard, not a hypothetical.** Noisebridge's retired gCal has five RRULEs with no `UNTIL`; it generates ~5 plausible events a week forever. Expansion must be horizon-bounded, and issue 0016's `max_stale_days` gate is what catches the underlying rot.

Sudo Room's export ignores `scope`, `limit` and `category` entirely — byte-identical responses regardless — so all clipping is client-side.

Known-good fixtures to test against, with counts recorded 2026-08-05:

- Ace `calendar/list/?ical=1` — 126 VEVENTs
- Sudo Room `?ical=1` — 5057 VEVENTs, 73 in horizon
- Frontier `cal-Sl7q1nHTRXQzjP2` — 262 VEVENTs, 26 upcoming
- Hacker Dojo Meetup iCal — exactly 10, hard cap, no pagination

Save fixtures under `tests/fixtures/` rather than hitting the network in unit tests.
