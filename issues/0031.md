# 0031 — Schedule the nightly run with launchd

| | |
|---|---|
| **Status** | open |
| **Module** | schedule |
| **Platform** | macOS |
| **First seen** | 2026-08-05 |

## Description

Run the pipeline nightly on the Mac mini. launchd, not cron — cron on macOS is deprecated and handles sleep badly.

## Expected behavior

- `~/Library/LaunchAgents/co.sstools.maker-calendar.plist`, `StartCalendarInterval` at 03:15, `RunAtLoad` false, stdout/stderr into `logs/`.
- Machine awake: `sudo pmset repeat wakeorpoweron MTWRFSU 03:10:00`.
- LM Studio's server running in headless / run-on-login mode.
- Absolute paths for everything.

## Notes

**The gotcha that will cost an evening: launchd does not read `~/.zshrc`.** `$MAKER_CALENDAR_CONTACT` and any other environment variables must be loaded from `.env` explicitly by the entry point, or carried in the plist's `EnvironmentVariables`. The loader fails loudly on a missing contact (issue 0005), so the failure mode is an aborted 03:15 run — visible in `logs/`, but only if someone looks.

LaunchAgents run only while the user is logged in. A LaunchDaemon would survive reboot but runs as root with no Homebrew paths and no shell profile. Prefer the agent plus auto-login.

Verify by running the plist manually first (`launchctl kickstart`) rather than waiting for 03:15.
